# RAG по отзывам покупателей о женской одежде и аксессуарах

Учебный RAG-проект на русскоязычных отзывах покупателей.

Проект показывает полный pipeline:

```text
данные → документы → чанки → индекс → поиск → demo-ответ с источниками
```

## Что делает проект

Система принимает вопрос пользователя, ищет релевантные фрагменты в отзывах покупателей и показывает ответ на основе найденных источников.

## Данные

В проекте используется открытый датасет RuReviews с отзывами о женской одежде и аксессуарах.

Источник: https://github.com/sismetanin/rureviews

В текущей версии в `data/raw/datasets.json` сохранено 1000 текстовых отзывов.

Подробнее: `doc/DATA.md`.

## Быстрый старт

```bash
uv sync
uv run python scripts/build_index.py
uv run streamlit run app/main.py
```

После запуска откройте Streamlit-приложение в браузере. В GitHub Codespaces нужно открыть forwarded port `8501`.

## Demo-вопросы

| Вопрос | Ожидание |
|---|---|
| Что покупатели пишут о размере? | Ответ по отзывам про размер, посадку, маломерность или большемерность |
| Что пишут о качестве товара? | Ответ по отзывам про качество ткани, пошив, внешний вид |
| Что пишут о платьях? | Ответ по отзывам, где упоминаются платья |
| Как оформить ипотеку? | Отказ, потому что в данных нет информации об ипотеке |

## Ограничения MVP

- Поиск реализован через TF-IDF, поэтому качество зависит от совпадения слов.
- Внешняя LLM не используется.
- Ответ формируется только на основе найденных фрагментов.
- Если релевантных фрагментов нет, система должна отказаться от ответа.
